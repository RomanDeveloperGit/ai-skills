# UI Style Reference

Применяй этот файл при создании и изменении любого UI. Цель — тёмный премиальный интерфейс с зелёными акцентами: спокойный, точный, элегантный, без визуального шума.

## 1. Направление

Формула: глубокий тёмный фон, ясная типографика, один зелёный акцент, мягкая глубина, аккуратные состояния.

Принципы:

- Строй иерархию контрастом и пространством, а не количеством цветов и рамок.
- Держи одно accent-действие на экран. Вторичные действия — нейтральные.
- Занимай акцентом единицы процентов площади: кнопка, активный пункт, фокус, ключевая цифра.
- Создавай глубину слоями фона, тонкой рамкой и мягкой тенью. Не свети всем подряд.
- Оставляй больше воздуха, чем кажется достаточным, но не разрывай связанные элементы.
- Проектируй сразу все состояния: hover, active, focus, disabled, loading, error, empty, selected.
- Добавляй уникальность в детали: ритм отступов, форма рамок, сдержанные переходы, аккуратные иконки. Не в декоративных эффектах.
- Следуй конвенциям: пользователь должен понимать интерфейс без обучения.
- Делай интерфейс приятным для глаза: низкая насыщенность фонов, мягкий контраст, отсутствие визуального шума.

Избегай:

- неонового зелёного и светящихся заливок на больших площадях;
- чистого чёрного `#000` и чистого белого `#fff`;
- радужных градиентов, градиентного текста и стеклянных панелей без смысла;
- теней у каждого блока и рамок у каждого элемента;
- радиусов больше `20px` у карточек и панелей;
- анимаций ради анимаций и бесконечных декоративных циклов;
- нескольких акцентных цветов, конкурирующих за внимание;
- текста мельче `12px` и низкоконтрастного текста;
- UI-библиотек и готовых наборов компонентов.

Правила:

- Меняй токен, а не отдельный компонент, если нужно поправить оттенок или ритм.
- Не добавляй новый токен под единичный случай. Сначала проверь существующую шкалу.
- Держи типографику в `rem`, отступы, радиусы и размеры контролов — в `px`. Не переводи одну и ту же шкалу в разные единицы и не используй `em` для глобальной сетки.
- Используй `--gap-*` для расстояний: `gap`, `padding`, `margin`. Не используй их для ширины, высоты и позиционирования.
- Задавай одинаковые промежутки через `gap` у контейнера, а не через `margin` у каждого ребёнка.
- Отрицательный отступ — `calc(-1 * var(--gap-8))`, не магическое число.
- Не добавляй `--gap-6`, `--gap-18` или `--gap-27` под единичный случай.
- Называй токены по роли, а не по цвету: `--color-text-secondary`, а не `--color-gray-400`.
- Не используй `--color-accent` для фонов больших секций.
- Не смешивай бренд-зелёный и success без визуальной разницы: добавляй иконку, текст или форму.
- Для границ контролов используй `--color-border-control`, для декоративных разделителей — `--color-border-subtle`.

## 3. Цвет

### Баланс

- Основная площадь — тёмные нейтральные фоны.
- 10–15% — текст и иконки; акцент — не более 10%.
- Один экран — одно accent-действие. Акцент в навигации и фокусе не конкурирует с ним.
- Если акцентов больше, пользователь не понимает главное действие.

### Применение зелёного

| Элемент | Как применять |
|---|---|
| Accent-кнопка | Сплошная заливка `--color-accent`, текст `--color-on-accent` |
| Secondary-кнопка | Нейтральный фон и рамка, без зелёного |
| Активный пункт навигации | `--color-accent-softer` + индикатор `--color-accent` |
| Ссылка | `--color-accent`, подчёркивание при hover |
| Фокус | Контур `2px` `--color-accent` с отступом `2px` |
| Выбранная строка | `--color-accent-softer` + рамка `--color-accent` |
| Успех | `--color-success` + иконка + текст, не только цвет |
| График | Акцент — первый ряд, остальные — приглушённые оттенки |

### Контраст

- Основной текст — не ниже `4.5:1` к фону.
- Крупный текст и границы контролов — не ниже `3:1`.
- Не полагайся только на цвет: добавляй иконку, подпись, форму или паттерн.
- Для мелкого зелёного текста используй `--color-accent-hover`, если базовый акцент не проходит по контрасту.
- На заливке акцента используй тёмный текст `--color-on-accent`, не белый.

## 4. Типографика

- Используй одну основную гарнитуру. Вторую подключай только для кода или явной редакционной задачи.
- Не используй больше двух начертаний в одном компоненте.
- Заголовки — `500–600`, основной текст — `400`, подписи — `500`.
- Не используй `700+` без причины: на тёмном фоне жирный текст выглядит грубо.
- Держи длину строки `60–75ch`; для форм и панелей — уже.
- Не центрируй длинные абзацы.
- Не используй `letter-spacing` на основном тексте.
- Для надзаголовков используй `11–12px`, `600`, uppercase, tracking `0.08em`.
- Для чисел в таблицах, статистике и ценах включай `font-variant-numeric: tabular-nums`.
- Обрезай длинный текст через `text-overflow: ellipsis`, но не скрывай критичные данные.
- Не опускайся ниже `12px`. Основной UI-текст — `13–14px`, текст для чтения — `16px`.

| Роль | Размер | Интерлиньяж | Начертание |
|---|---|---|---|
| Display | `48px` | `1.1` | `500` |
| H1 | `36px` | `1.15` | `600` |
| H2 | `28px` | `1.2` | `600` |
| H3 | `22px` | `1.3` | `600` |
| Body large | `16px` | `1.6` | `400` |
| Body | `14px` | `1.5` | `400` |
| UI label | `13px` | `1.2` | `500` |
| Caption | `12px` | `1.4` | `400` |
| Overline | `11px` | `1.2` | `600`, uppercase |

## 5. Сетка и ритм

Строй расстояния по шкале `--gap-*`: `0`, `2`, `4`, `8`, `12`, `16`, `20`, `24`, `32`, `40`, `48`, `56`, `64`, `72`, `80`, `96`, `128`.

| Токен | Где использовать |
|---|---|
| `--gap-2` / `--gap-4` | Оптическая правка, иконка и текст, плотные пары |
| `--gap-8` / `--gap-12` | Внутри контрола, label–поле, компактная группа |
| `--gap-16` / `--gap-20` | Базовый gap, карточка, строка формы |
| `--gap-24` / `--gap-32` | Сетка, блоки, секции внутри страницы |
| `--gap-40`–`--gap-64` | Крупные секции |
| `--gap-72`–`--gap-128` | Страничные ритмы, hero, пустые состояния |

- Начинай с `8/12/16`. `2/4` — только для оптики, не для больших отступов.
- Не используй токены расстояний для ширины, высоты и позиционирования.
- Не добавляй `--gap-6`, `--gap-18` или `--gap-27` под единичный случай.
- Держи вертикальный ритм: связанные элементы — `8–12px`, группы — `16–24px`, секции — `40–64px`.
- Отступы страницы: `16px` на мобильном, `24px` на планшете, `32–40px` на десктопе.
- Брейкпоинты: `640`, `900`, `1200`. Не заводи отдельные в каждом компоненте.
- Максимальная ширина контента — `1200px`; для чтения — `68ch`; для формы — `480–560px`.
- Сетка: `12` колонок на десктопе, `8` на планшете, `4` на мобильном. Gutter — `24px` / `16px`.
- Не растягивай форму и текстовый блок на всю ширину экрана.
- Не вкладывай карточку в карточку глубже одного уровня.
- На мобильном переводи сложные двухколоночные блоки в одну колонку, а не уменьшай всё.
- Не допускай горизонтального скролла. Для таблиц используй локальный контейнер с прокруткой.
- Держи одинаковые левые края у заголовков, текста и контролов.

### Плотность

| Элемент | Высота |
|---|---|
| Малый контрол | `32px` |
| Обычный контрол | `40px` |
| Крупный контрол | `48px` |
| Строка таблицы | `48–56px` |
| Пункт меню | `36–40px` |
| Иконочная кнопка | `32–40px` |

## 6. Глубина и поверхности

- Используй три уровня: `--color-bg`, `--color-surface`, `--color-surface-hover`.
- Карточка: фон `--color-surface`, рамка `1px` `--color-border`, радиус `14–16px`, padding `20–24px`.
- Тень добавляй только плавающим элементам: dropdown, modal, toast, popover.
- Для карточек достаточно рамки и лёгкого верхнего блика `--highlight-top`.
- Hover-подъём — не больше `1–2px` и только для кликабельной карточки.
- Backdrop blur `8–12px` — только для модальных окон и оверлеев, не для каждой панели.
- Градиент допустим как мягкий верхний блик поверхности или заливка accent-кнопки. Не делай градиентные карточки и текст.
- Разделители — `1px` `--color-border-subtle` или отступ. Не обрамляй каждый блок.

## 7. Движение

- Микро-взаимодействия: `120–180ms`.
- Панели, dropdown, табы: `180–260ms`.
- Модальные окна и оверлеи: `260–320ms`.
- Вход — `--ease-standard`, выход — `--ease-exit`.
- Анимируй `transform` и `opacity`. Не анимируй `width`, `height`, `top`, `left`.
- Hover-подъём — `1–2px`, без пружин и отскоков.
- Появление страницы — мягкий fade и сдвиг не больше `8px`.
- Не используй бесконечные декоративные анимации. Spinner — только для действия, skeleton — для контента.
- Уважай `prefers-reduced-motion: reduce`: отключай переходы и циклические анимации.

## 8. Компоненты

### 8.1. Button

Анатомия: контейнер, слот слева, label, слот справа, индикатор загрузки.

- `view` задаёт иерархию: `accent`, `secondary`, `outline`, `ghost`, `text`.
- `tone` задаёт смысл: `default`, `danger`. Не смешивай tone и view.
- `accent` — главное действие, зелёная заливка. Одно на экран.
- `secondary` — обычное действие: нейтральный фон и рамка.
- `outline` — второстепенное действие на плотном фоне: прозрачный фон и рамка.
- `ghost` — малозначимое действие: без рамки, с hover-подложкой.
- `text` — inline-действие, как ссылка. Не используй его для submit.
- `danger` — только разрушительное действие. С `secondary`/`outline` — soft-фон, с `accent` — сплошная заливка для финального подтверждения.
- Не заводи отдельный `primary`, если он дублирует `accent`: иерархия должна быть однозначной.
- Размеры — числом: `32`, `40`, `48`, `56` (px). Не используй `sm/md/lg/xl` для размеров контролов.
- Радиус растёт с размером: `8/10/12/14px`.
- Горизонтальный padding: `12/16/20/24px`; иконка: `14/16/18/20px`.
- `block` растягивает кнопку на ширину контейнера. На мобильном основная кнопка формы обычно `block`.
- Слоты `leftAddon`/`rightAddon` — для декоративных иконок. Без label кнопка становится квадратной, добавь `aria-label`.
- `loading`: сохраняй ширину, скрывай label и слоты, показывай spinner по центру; держи минимум `300–500ms`, чтобы кнопка не мигала; ставь `aria-busy`, блокируй повторный клик.
- `disabled`: opacity `0.45`, `cursor: not-allowed`, без тени и hover. Loading не должен выглядеть как disabled.
- Focus-visible: контур `2px` `--color-accent`, offset `2px`. Hover только при `@media (hover: hover)`.
- Для перехода по URL используй ссылку с семантикой кнопки или отдельный `ButtonLink`, не `div` с `onClick`.
- Не делай все кнопки зелёными, не используй uppercase и не переноси label на две строки без причины.
- `pill`-форму используй для фильтров и тегов, не для форм.

### 8.2. TextField

Анатомия: label, контрол, иконка, hint/error.

- Label — над полем, `13px`, `500`, отступ `4–8px`.
- Контрол — высота `40–48px`, padding `12–16px`, радиус `10px`.
- Фон — `--color-surface`, рамка `1px` `--color-border-control`.
- Placeholder — `--color-text-muted`, не заменяет label.
- Focus — рамка `--color-accent` + кольцо `3px` `--color-accent-soft`.
- Error — рамка `--color-danger`, иконка, текст ошибки `12px`, `aria-invalid="true"`.
- Hint — `12px`, `--color-text-muted`, отступ `4–8px`.
- Disabled — opacity `0.5`, курсор `not-allowed`; при необходимости добавь нейтральный фон.
- Read-only — нейтральный фон, без изменения рамки при focus.
- Иконка — `16–18px`, `--color-text-muted`, `aria-hidden="true"`.
- На мобильном используй `font-size: 16px`, чтобы браузер не масштабировал страницу.
- Ошибка и hint связаны с полем через `aria-describedby`. Ошибка не должна исчезать при вводе, пока пользователь не исправит поле.
- Textarea использует ту же анатомию: `min-height: 96–120px`, `resize: vertical`, тот же focus и error.

### 8.3. Select

- Держи ту же высоту и рамку, что у TextField.
- Шеврон — `16px`, `--color-text-muted`, справа.
- Меню — `--color-surface-hover`, рамка, радиус `12px`, тень `--shadow-md`, max-height `280px`.
- Пункт — `36–40px`, hover `--color-surface-active`, выбранный — `--color-accent-softer`.
- Поддерживай клавиатуру: стрелки, Enter, Escape, Home/End.
- Нативный `select` допустим, если стилизация не ломает платформенное поведение.

### 8.4. Checkbox, Radio, Switch

- Размер чекбокса и радио — `18–20px`, радиус `4px` / `50%`.
- Checked — заливка `--color-accent`, отметка `--color-on-accent`.
- Focus — кольцо `3px` `--color-accent-soft`.
- Label кликабелен целиком; отступ `8–10px`.
- Switch — `36×20px`, thumb `16px`, включённый трек `--color-accent`.
- Switch используй для мгновенных настроек, не для подтверждения формы.
- Не используй чекбокс как кнопку действия.

### 8.5. Card

- Фон `--color-surface`, рамка `1px`, радиус `14–16px`, padding `20–24px`.
- Заголовок — `16–18px`, `600`; описание — `13–14px`, `--color-text-secondary`.
- Кликабельная карточка — это ссылка или кнопка, а не `div` с `onClick`.
- Hover: рамка `--color-border-strong`, подъём `1px`.
- Focus-visible: контур вокруг всей карточки.
- Не добавляй тень, если карточка не плавающая.
- Не вкладывай карточки без явной иерархии.

### 8.6. Dialog

- Оверлей — `--color-overlay` + blur `8–10px`.
- Панель — `--color-surface`, рамка, радиус `20px`, padding `24px`, max-width `480–640px`.
- Заголовок — `18–22px`, `600`; описание — `14px`, `--color-text-secondary`.
- Действия — справа, основное действие одно; на мобильном — на всю ширину.
- Закрытие: кнопка `40×40`, Escape, клик по оверлею, если действие не разрушительное.
- Блокируй скролл фона, удерживай фокус внутри, возвращай фокус на триггер.
- Не используй модальное окно для простого подтверждения, если хватает inline-состояния.

### 8.7. Dropdown и Menu

- Панель — `--color-surface-hover`, рамка, радиус `12px`, padding `4–6px`, тень `--shadow-md`.
- Пункт — `36–40px`, hover `--color-surface-active`, destructive — `--color-danger`.
- Разделитель — `1px` `--color-border-subtle`, отступ `4px`.
- Открытие по клику и клавиатуре; закрытие по Escape и клику вне.
- Не помещай в меню больше `7–8` пунктов без поиска или группировки.

### 8.8. Tabs

- Активная вкладка — `--color-text`, индикатор `2px` `--color-accent`.
- Неактивная — `--color-text-muted`, hover `--color-text-secondary`.
- Переключение стрелками, `role="tablist"`, корректные `aria-selected`.
- Не используй pills для навигации, если это не фильтры.

### 8.9. Toast

- Позиция — правый нижний угол, max-width `360px`.
- Фон — `--color-surface-hover`, рамка, радиус `12px`, тень `--shadow-lg`.
- Иконка статуса, заголовок `14px`, описание `13px`, закрытие.
- Автоскрытие `4–6s`; пауза при hover и focus.
- `aria-live="polite"`, максимум `3` одновременно.
- Не показывай тост для ошибки, которую нужно исправить в форме.

### 8.10. Table и List

- Заголовок — `11–12px`, uppercase, `--color-text-muted`.
- Строка — `48–56px`, hover `--color-surface-hover`.
- Выбранная строка — `--color-accent-softer` + левый индикатор.
- Числа — справа, `tabular-nums`.
- Длинный текст — ellipsis с tooltip или раскрытием.
- На мобильном — карточки или горизонтальный скролл, не сжатие колонок.
- Пустое состояние — внутри таблицы, а не вместо всей страницы.

### 8.11. Badge и Avatar

- Badge — высота `20–24px`, padding `6–8px`, радиус `--radius-full`, шрифт `11–12px`.
- Фон badge — соответствующий soft-токен (`--color-success-soft`, `--color-warning-soft`, `--color-danger-soft`), текст — семантический цвет.
- Не делай все badge зелёными.
- Avatar — `24/32/40/48px`, круг, fallback с инициалами, рамка `1px` `--color-border`.
- Статус — точка `6–8px` с рамкой цвета фона.

### 8.12. Skeleton, Empty, Error

- Skeleton повторяет финальную геометрию и не вызывает сдвиг.
- Пульсация — `1.5–2s`, приглушённая; при reduced motion — статичный блок.
- Empty: иконка `24–32px`, заголовок `16px`, описание `13–14px`, одно действие.
- Error: иконка danger, понятный текст, кнопка повтора, сохранение введённых данных.
- Не показывай пустой экран вместо загрузки или ошибки.
- Не используй spinner на весь экран, если можно показать skeleton контента.

### 8.13. Навигация

- Sidebar — `240–280px`, пункт `36–40px`, иконка `18–20px`.
- Активный пункт — `--color-accent-softer`, левый индикатор `2px`, текст `--color-text`.
- Header — `56–64px`, нижняя рамка `--color-border-subtle`.
- Sticky-header — с blur и полупрозрачным фоном, но без яркой тени.
- Breadcrumbs — `12–13px`, `--color-text-muted`, текущая страница — `--color-text-secondary`.

### 8.14. Формы

- Label — сверху. Floating label допустим только при безупречной доступности и поведении.
- Группы полей — `20–24px`; действия — `24–32px` от последнего поля.
- Две колонки — только для коротких связанных полей. На мобильном — одна.
- Обязательные поля помечай текстом или `aria-required`, не только звёздочкой.
- Ошибку показывай рядом с полем и фокусируй первое невалидное поле после submit.
- Accent-кнопка формы — одна. Отмена — secondary или ghost.
- Не блокируй submit без объяснения; показывай, что не так.

## 9. Состояния

| Состояние | Визуал | Правило |
|---|---|---|
| Default | Базовые токены | Ничего не выделяй без причины |
| Hover | Фон на шаг светлее | Только на устройствах с hover |
| Active | Фон темнее, сдвиг `1px` | Короткий отклик |
| Focus-visible | Контур `2px` accent | Никогда не убирай |
| Disabled | Opacity `0.45` | Объясняй причину, если действие важно |
| Loading | Spinner или skeleton | Сохраняй размеры |
| Error | Danger-рамка, иконка, текст | Не только цвет |
| Empty | Иконка, заголовок, действие | Не оставляй пустоту |
| Selected | Accent-soft фон, индикатор | Не только цвет |
| Read-only | Нейтральный фон | Не путай с disabled |
| Success | Success-иконка, текст | Не полагайся на зелёный |

- Не допускай layout shift при переходе между состояниями.
- Loading не должен выглядеть как disabled: сохраняй цвет, размер и контраст, блокируй только повторный клик.
- Держи индикатор загрузки минимум `300–500ms`, чтобы при быстром ответе кнопка не мигала.
- Не отключай focus и не заменяй его на `outline: none` без альтернативы.
- Focus-visible показывай только при навигации с клавиатуры, не при клике мышью.
- Если элемент должен оставаться в порядке фокуса, используй `aria-disabled` и блокируй действие; иначе — `disabled`.
- Если действие недоступно, покажи причину рядом или в tooltip.
- Hover-эффект не должен быть единственным способом понять кликабельность.

## 10. Доступность

- Проверяй контраст текста, иконок и границ контролов.
- Все интерактивные элементы доступны с клавиатуры.
- Порядок фокуса совпадает с визуальным.
- Иконочные кнопки имеют `aria-label`.
- Формы связаны с label через `htmlFor`/`id`.
- Ошибки и подсказки связаны через `aria-describedby`.
- Модальные окна: `role="dialog"`, `aria-modal="true"`, focus trap, Escape, возврат фокуса.
- Toast и динамические сообщения — `aria-live`.
- Изображения имеют `alt`; декоративные иконки — `aria-hidden`.
- Не используй цвет как единственный носитель смысла.
- Поддерживай масштаб `200%` без потери контента.
- Не фиксируй высоту текстовых контейнеров.
- Уважай `prefers-reduced-motion`.
- Проверяй интерфейс только клавиатурой и скринридером перед сдачей.

## 11. Реализация

- Общие примитивы — в `shared/ui`, только после второго реального потребителя.
- Одноразовые компоненты — в `ui` страницы.
- Не подключай UI-библиотеку и не оборачивай готовые компоненты.
- Держи стили рядом с компонентом: `ui.module.css` или принятый в проекте способ.
- Глобальные токены и reset — в `app/styles`.
- Не используй глобальные селекторы для компонентов.
- Не используй inline-стили, кроме динамических CSS-переменных.
- Не используй `!important`.
- Пробрасывай нативные атрибуты и `ref` наружу.
- Держи компонент управляемым или неуправляемым, но не смешивай оба режима без необходимости.
- Не добавляй полиморфные пропсы и мега-конфигурацию без реальных сценариев.
- Композируй простые примитивы вместо одного универсального компонента.
- Не держи бизнес-логику в `shared/ui`.
- Иконки — inline SVG с `currentColor`, размер `16/20/24`, stroke `1.5–1.75`.
- Не подключай иконочную библиотеку без необходимости.
- Изображения — с `aspect-ratio`, `object-fit: cover` и радиусом по контексту.
- Шрифты — не больше двух семейств; по возможности self-host и `font-display: swap`.

### Структура примитива

```text
shared/ui/button/
  ui.tsx
  ui.module.css
  index.ts
```

```ts
// shared/ui/button/index.ts
export { Button } from './ui';
export type { ButtonProps } from './ui';
```

### Три уровня токенов

1. Глобальные: `--color-*`, `--gap-*`, `--radius-*`, `--text-*`.
2. Семантические: `--color-text-secondary`, `--color-danger`, `--color-on-accent`.
3. Компонентные: `--button-bg`, `--button-fg`, `--button-border`.

Компонентные токены держи в компоненте, не в `:root`. Вариант меняет токены, а базовое правило — свойства.

```css
.button {
  --button-bg: var(--color-surface);
  --button-fg: var(--color-text);
  background: var(--button-bg);
  color: var(--button-fg);
}

.button[data-view='accent'] {
  --button-bg: var(--color-accent);
  --button-fg: var(--color-on-accent);
}
```

- Не повторяй `background`, `color`, `border` в каждом варианте.
- Не смешивай глобальные и компонентные токены в одном слое.
- Не выноси компонентные токены в `:root`, если их не переопределяет тема.

### Контракт компонента

- Определи пропсы до реализации: `view`, `size`, `tone`, `block`, `isLoading`, слоты.
- `view` — визуальная иерархия, `tone` — семантика, `size` — размер, `block` — раскладка.
- Передавай визуальные варианты и состояния в CSS через `data-view`, `data-size`, `data-tone`, `data-loading`; классы оставляй для раскладки и композиции.
- Не плоди булевы флаги `isPrimary`, `isSecondary`, `isDanger`.
- Не добавляй пропс, пока нет второго реального сценария.
- Один компонент — один набор состояний и одно поведение загрузки.
- Для общего примитива зафиксируй контракт: назначение, варианты, размеры, состояния, слоты.

### Адаптивность

- Держи один компонент, а не `ButtonMobile`/`ButtonDesktop`.
- Меняй размер, padding и направление через CSS или пропсы.
- Отдельные mobile/desktop варианты — только когда различается взаимодействие: bottom sheet вместо modal, нативный picker вместо dropdown.
- Тач-цель — минимум `44×44px`; на мобильном основная кнопка формы — `block`.
- Не дублируй разметку ради брейкпоинта.

### Layout-примитивы

- Для расстояний используй `gap` у flex/grid, а не `margin` у детей.
- `Stack`, `Inline`, `Gap` — только если один и тот же ритм повторяется в 2+ местах.
- Не создавай компонент на каждый размер отступа; размер передавай токеном.
- Если примитив нужен, держи его в `shared/ui`, а не в `shared/components`.

Примеры реализации — в [ui-examples.md](ui-examples.md).

## 12. Рецепты экранов

### Вход и регистрация

- Центрируй карточку `400–440px` на фоне `--color-bg` с едва заметным радиальным зелёным свечением.
- Заголовок `28–36px`, описание `14px`, поля — в одну колонку.
- Одна accent-кнопка отправки, один secondary-переход.
- Не используй стоковые изображения и тяжёлые иллюстрации.

### Список

- Header: заголовок, короткое описание, accent-действие.
- Фильтры — отдельная строка, без тяжёлой панели.
- Контент — карточки или таблица с одинаковым ритмом.
- Пустое состояние — с действием, а не только с текстом.
- Пагинация — внизу, ненавязчивая.

### Детальная страница

- Верх: заголовок, статус, метаданные, действия.
- Основной контент — `2:1` с боковой панелью на десктопе, одна колонка на мобильном.
- Опасные действия — в отдельном блоке или меню, не рядом с accent.
- Длинные тексты — `68ch`, не на всю ширину.

### Настройки

- Слева — навигация разделов, справа — форма `480–560px`.
- Группы — с заголовком и коротким описанием.
- Сохранение — sticky-панель или accent внизу группы.
- Несохранённые изменения — предупреждение при уходе.

- Неоновая заливка и свечение вокруг каждого элемента.

- Радиус `24px+` у всех элементов.
- Placeholder вместо label.
- Иконочная кнопка без подписи и `aria-label`.
- `div` с `onClick` вместо кнопки или ссылки.
- Отключённый focus и `outline: none`.
- Spinner на весь экран вместо skeleton.
- Модальное окно для любого действия.
- Текст мельче `12px` и низкий контраст.
- Центрирование длинных абзацев.

- Бесконечные анимации и parallax.

- Отдельный `Gap`/`Stack` на каждый размер отступа.

- [ ] Отступы только из шкалы `--gap-*`, без `13px`, `17px`, `27px`.
